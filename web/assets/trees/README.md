# Bark and leaf textures from EZ-Tree

Images only, no code. From EZ-Tree by Daniel Greenheck, MIT licence
(`LICENSE`), https://github.com/dgreenheck/ez-tree, npm `@dgreenheck/ez-tree`
1.1.0, folder `src/lib/assets/` (willow bark left out).

The bark textures' own README (`bark/README.md`) names their sources:
Poly Haven (CC0) and TextureCan. Drone World's trees are generated by its own
code (`../../src/trees.js`); only these images come from EZ-Tree.
